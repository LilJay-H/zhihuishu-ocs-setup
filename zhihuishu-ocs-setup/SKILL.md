# 智慧树 OCS 安装与首次使用

目标：让第一次使用的 Windows 用户从未安装走到自己的课程正常运行。流程依据[官方软件教程](https://docs.ocsjs.com/docs/app)、[脚本教程](https://docs.ocsjs.com/docs/script/)和[软件辅助说明](https://docs.ocsjs.com/docs/script-helper)：智慧树需要软件辅助，必须在 **OCS 内新建并启动的浏览器** 中使用。

## 先向用户讲清这是什么（固定表述，开口前先说，不扩写）

先原样告诉用户下面这段，再动手安装：

> OCS 网课助手是一个开源工具，由“OCS 桌面软件”和一个浏览器脚本组成。装好后，你在它自带的浏览器里登录智慧树、打开课程，脚本会替你做这些事：自动续播、自动进入下一节、处理视频中途弹出的测验、按设定倍速播放。登录由你自己完成。
>
> 接下来我会帮你装好桌面软件，然后你自己做四步：初始化、新建浏览器、登录、试用约一分钟。
>
> 有两点要知道：智慧树倍速超过 1.5x 有封号风险，建议保持默认；是否使用助手请自行评估，平台可能不允许。

只讲这几项能力。不介绍题库、答题、作业考试等其他功能，用户追问时再按官方文档如实回答。

## Agent 自动安装

在 Windows x64 上运行（PowerShell 或 Bash 均可；`-ExecutionPolicy Bypass` 避免默认策略拦截脚本）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File '<skill-dir>\ocs-setup.ps1' -Launch
```

脚本复用已安装的 OCS；否则从 GitHub 下载官方最新稳定安装包（默认存到 `Downloads\ocs-setup`，可用 `-Destination` 指定），核对发布大小和 SHA256、检查 NSIS 格式，以 `/S` 静默安装、核对落盘版本后打开 OCS。输出 JSON，失败时退出码为 1。无需源码或 Node、Python 等开发工具。

下载沿用系统代理设置。安装包是当前用户安装（装到 `%LOCALAPPDATA%\Programs\OCS Desktop`），本身不需要管理员权限；OCS 主程序请求最高可用权限，管理员账户打开它时可能弹出 UAC，由用户确认。JSON 里 `launchError` 不为空，表示已装好但没能打开，请用户从开始菜单打开 OCS。

后续界面由用户自己操作，默认不用 computer use 或浏览器自动化；如出现系统确认，由用户完成。没有终端工具时，给出[GitHub 发布页](https://github.com/ocsjs/ocs-desktop/releases)或官方教程中的下载列表。

## 一次交付后续路线

报告实际安装结果后，一次讲清以下步骤，让用户连续完成，卡住再发截图：

1. 点窗口左上角菜单 **工具 → 初始化设置**，在弹窗里点 **一键初始化**，等浏览器、脚本管理器和脚本准备完成（约十秒到数十秒）。主程序打开不等于已初始化；如果弹窗已自动出现，直接点即可。
2. 点右上角 **新建浏览器**，然后启动它。在这个浏览器里自己登录智慧树、处理验证码，再进入课程。
3. 页面出现 OCS 面板后，先保持 **视频倍速** 1x、**复习模式** 关闭（都是默认值；面板提示智慧树超过 1.5x 有封号风险），观察约一分钟。提前告知用户：进入视频页后可能自动开始。试用结束关闭视频标签页；遇到题目、验证码或报错就提前停止。

完成时核对：初始化已完成、课程页有面板、视频实际在正常播放、已停止。只报告有证据的结果，不把看到面板或计时增长当作平台已保存进度的证明。下次从 OCS 启动同一个浏览器继续。

## 卡住时再处理

- 从已完成的步骤接着往下走，不要求逐步汇报，也不预先盘问环境。截图可用 `Win+Shift+S` 后粘贴，注意避开密码等私人信息。
- 安装失败或超时不自动重跑。确认错误后，可用 `-DownloadOnly` 只下载，再把实际安装包路径给用户手动运行；发布方没有提供摘要时只能确认大小，不能说官方哈希匹配。GitHub 下载失败或太慢时，可改用官方软件教程下载列表里的 CDN 安装包，但要如实告知它目前是旧版 2.9.24，也没有发布哈希。浏览器下载的安装包未签名，SmartScreen 可能拦截，点“更多信息”再点“仍要运行”。不要卸载用户现有的 OCS。
- 初始化或面板异常时先看截图，确认已初始化、用的是 OCS 新建的浏览器。智慧树页面元素挤在一起时，按官方说明把页面缩放调到 50% 或 75% 并刷新。重复失败又没有新线索就停止尝试。

如果当前请求只要求制作或讲解，就按这个范围处理。首次使用默认不扩展到题库、作业考试或长期挂机。
