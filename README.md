# 智慧树 OCS 安装 Skill

让 AI Agent 帮你安装官方 OCS 桌面端，再指导你完成初始化、创建浏览器、登录智慧树和约一分钟的首次试用。

**适用 Windows 10/11 x64。** Agent 需要本地文件访问、终端和联网能力；运行只依赖 Windows 已有的 PowerShell。默认不用 computer use，界面和登录由你操作，卡住时发截图即可。

## 使用

1. [下载 v10 技能包](https://github.com/LilJay-H/zhihuishu-ocs-setup/releases/download/v10/zhihuishu-ocs-setup-v10.zip)，解压，保留两个文件在同一文件夹中。
2. 将解压目录提供给 Agent，发送：

   > 请读取这个文件夹里的 SKILL.md，帮我安装智慧树助手。

   如果 Agent 已安装并发现本技能，直接说“帮我安装智慧树助手”即可。
3. Agent 安装并打开 OCS 后，按指引完成 **工具 → 初始化设置 → 一键初始化 → 新建并启动浏览器 → 登录课程**。

```text
zhihuishu-ocs-setup/
├── SKILL.md         Agent 指引、人工步骤和排错
└── ocs-setup.ps1    官方下载、校验、静默安装和启动
```

安装脚本会复用已有 OCS，或获取官方最新稳定版，核对发布大小和 SHA256 后安装。安装和打开是两个结果：打开失败时会单独返回 `launchError`。系统权限弹窗由用户处理。

## 给同学做一次短测

建议用尚未安装过 OCS 的 Windows 电脑，只给测试者技能包和上述启动语，让他按 Agent 指引自行完成。进入课程可能自动播放；先用 1x，观察约一分钟后关闭视频标签页。卡住或遇到题目、验证码、错误时提前停止并截图反馈。

反馈三件事即可：能否走完全程、哪里不清楚或卡住、有没有弹窗或错误。截图请避开密码等私人信息。

## 验证范围

v10 对应的安装路径已在作者电脑验证：重新下载、发布摘要校验、静默安装、版本识别和程序启动均成功，用户确认课程正常播放。测试保留了既有浏览器数据。

默认 UAC 设置下的弹窗、完全首次初始化、新用户对固定讲解的理解仍需新机验证；视频弹题处理未独立实测。播放正常不等于平台已保存学习进度。首次使用范围不包含题库、作业考试或长期挂机。
